# Mall Customers Clustering with DBSCAN

## 📌 Overview
This project applies **DBSCAN clustering** to the Mall Customers dataset, focusing on **Annual Income** and **Spending Score**.  
Unlike K-Means, DBSCAN can discover clusters of arbitrary shape and detect noise points.

---

## 📂 Dataset
- **File:** `Mall_Customers (1).csv`
- **Features used:**
  - `Annual_Income_(k$)`
  - `Spending_Score`
---

## 📊 Visualization
- Each cluster is shown in a different color.
- Noise points (`-1`) are marked in **black (X)**.

---

## 🚀 Results
- DBSCAN successfully groups customers based on **income vs spending behavior**.
- Noise points represent customers that don’t fit into any dense cluster.
